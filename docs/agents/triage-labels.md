# Rótulos de triagem

| Papel canônico | Rótulo no tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação do mantenedor |
| `needs-info` | `needs-info` | Aguarda informações adicionais |
| `ready-for-agent` | `ready-for-agent` | Está especificado e pronto para um agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será implementado |

Quando um skill mencionar um papel canônico, use o rótulo correspondente desta tabela.
